Project Overview
The ICC World Cup Analysis project uses Microsoft Power BI to analyze cricket tournament data and present meaningful insights through interactive dashboards. It focuses on exploring team performance, match results, rankings, and tournament trends to support data-driven analysis.

Project Objectives
•	Analyze ICC World Cup match results and team performance.
•	Explore team rankings and performance trends.
•	Identify winning patterns and tournament statistics.
•	Build an interactive dashboard for easy data exploration.

Tools & Technologies
•	Microsoft Power BI – Data visualization and dashboard development
•	Power Query – Data cleaning and transformation
•	DAX – Calculated measures and KPIs
•	Data Modeling – Structuring and managing data relationships

Dashboard Features
•	Team Performance Analysis: Compare team results and performance.
•	Match Analysis: Explore match outcomes and winning trends.
•	Team Rankings: Analyze rankings and compare teams.
•	Interactive Filters: Use slicers to explore specific teams, matches, and other available data dimensions.
•	KPI Visualizations: Present key statistics through cards, charts, and other visuals.

Key Analysis Areas
1.	Match results and win patterns.
2.	Team-wise performance comparison.
3.	ICC team ranking analysis.
4.	Tournament statistics and performance trends

Skills Demonstrated
•	Data cleaning and transformation
•	Data modeling
•	DAX calculations and KPI development
•	Interactive dashboard design
•	Data analysis and visualization
•	Business intelligence reporting
